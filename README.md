# WEFLOW

> 문의로 이어지는 홈페이지를 만드는 웹 제작 서비스 랜딩페이지

WEFLOW는 홈페이지 제작, 광고 연동, 운영 관리, SEO 최적화, 사후관리까지 한 번에 보여주는 비즈니스형 웹사이트입니다.

## 주요 기능

- 메인 랜딩페이지
- 서비스 소개
- 6단계 제작 프로세스
- 광고 운영 · 사후관리 시스템
- 포트폴리오 / 성공사례
- 고객 후기 슬라이더
- 무료 진단 신청 유도
- 반응형 웹 디자인

## 제작 목적
